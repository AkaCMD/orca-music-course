ORCA / MUSIC FOR GAMES / LESSON 04

听出距离，而不只记音名

用半音、三度、五度和八度，控制旋律是靠近还是跃起。

约 18 分钟 · 终端 Orca · GeneralUser GS

完成这一课：能比较四种音程，并为同一动机选择小步移动或较大的跳进。

先回想一个旧问题

不看第一课：D2 与 D4 哪个发声更密？再想想门长与触发间隔是否是同一件事。

这次需要的知识

半音是这次量距离的单位

在十二平均律中，相邻半音相差一个 MIDI 编号。C 到 D 是 2 个半音，C 到 E 是 4 个，C 到 G 是 7 个。音程还需要字母名称：C 到 E 包含 C、D、E 三个字母位置，叫三度；4 个半音的这个三度是大三度。

八度保留音名，改变音区

同一个 C 向上八度相差 12 个半音。本地终端 Orca 的 5C 是 MIDI 60，6C 是 MIDI 72。这个数字与常见教材的科学音高标记不同；要比较音高，优先看 MIDI 编号。

Orca 用小写表示升半音

音名格里的小写 c 表示 C♯，d 表示 D♯，而不是“大写音的低八度”。延伸字母 J 表示下一音区的 C，所以终端 5J 等同 6C。示例 CDCECGCJ 依次比较 C-D、C-E、C-G、C-高C。

在终端中练习

先保存已有作品；Ctrl+D 或 F1 打开菜单，在 Open... 加载示例，在 Set BPM... 设 90。空格暂停，Ctrl+R 归零，再开始比较。

  1. 先试听「逐组比较」，每两个音是一组：低音 C 返回后，再听另一个距离。用手势标记第二音离 C 有多远。
  2. 打开网格，只改 T 右侧的 CDCECGCJ。用 CDCD 与 CGCG 分别做一版。保持 8 步时可写 CDCDCDCD 与 CGCGCGCG。
  3. 在单音或整条旋律对应的 MIDI 音区格，把 5 改成 6。先预测：音高升八度，BPM 会不会改变？
  4. 试一次把音名格里的 C 改为 c；听升高的半音，再恢复。自动序列请改 T 的音符表。

编辑提示：只改 T 右侧音名，或整条轨道的音区参数。J 是下一音区的 C，延伸字母映射见总速查。

检查理解

在本地终端版中，5C 改为 6C，音高怎样变化？

先凭记忆作答，选择后即时反馈。

显示判断方法

音区加 1 对应增加 12 个半音。速度由 BPM 决定。先预测再验证，检查自己能否应用概念。

做一份自己的版本

用 C、D、E、G 写一个“小步接近，再跳起”的 8 音动机。标出一处 2 半音和一处 7 半音的距离，最后回到 C。

把原版与自己的版本各保存一份。先只改变一个量做比较，再决定是否保留。

自评与复习

隔一段时间再来：先不看网格说出做法，再打开文件核对。向老师反馈“我改了哪一格、预期怎样、实际听见怎样”，或直接追问不清楚的概念。勾选与答案不会自动变成学习记录。
