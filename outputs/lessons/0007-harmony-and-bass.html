ORCA / MUSIC FOR GAMES / LESSON 07

用和弦推进四个小节

让低音标出 C、Am、F、G，再给它们补上和弦音。

约 22 分钟 · 终端 Orca · GeneralUser GS

完成这一课：运行并改写一个四小节和弦循环，听清低音与和声的关系。

先回想一个旧问题

把 C 大三和弦的三个音先说出来。再想：若整组音一起提高八度，和弦的大小性质会改变吗？

这次需要的知识

一个小节可以承载一个和弦

本例四小节依次为 C、Am、F、G，每小节四拍。它们分别包含 C-E-G、A-C-E、F-A-C、G-B-D。在 C 大调中可标作 I、vi、IV、V。这里的罗马数字表示相对主音的位置与和弦类型。

根音线让变化更容易听见

低音单独播放 C、A、F、G，帮助标识当前根音。最低音未必总是根音；本课为了看清关系，先让低音明确承担根音。听和弦循环时，在每个小节第一拍报出当前根音。

顺序和回归形成方向感

比较 C-Am-F-G 与 C-F-Am-G。和弦集合相同，顺序不同。在这次 C 大调语境中，G 回到 C 可以形成较明确的回归感。它是一种可用的路径，仍需要结合具体旋律和画面选择。

在终端中练习

先保存已有作品；Ctrl+D 或 F1 打开菜单，在 Open... 加载示例，在 Set BPM... 设 90。空格暂停，Ctrl+R 归零，再开始比较。

  1. 先只观察低音块，它的每个字符保持一小节。gC4 中左侧 g 代表 16 帧，计数器每小节换一次。
  2. 听第一版，跟着数四个小节；每小节开始报出 C、Am、F、G。
  3. 打开重排版，比较中间两个小节调换后的走向。门长、力度与 BPM 保持一致。
  4. 改写自己的版本时，要同时调整低音与三条和弦声部，确保它们仍对应同一个和弦。

检查理解

本课从 C-Am-F-G 改为 C-F-Am-G，直接改变什么？

先凭记忆作答，选择后即时反馈。

显示判断方法

使用同一套和弦与音源，但和弦出现的顺序变化了。先预测再验证，检查自己能否应用概念。

做一份自己的版本

用 C、Am、F、G 排一个自己的四小节顺序。写出四个根音，再选其中一小节列出三和弦的三个音。解释末小节怎样接回开头。

把原版与自己的版本各保存一份。先只改变一个量做比较，再决定是否保留。

自评与复习

隔一段时间再来：先不看网格说出做法，再打开文件核对。向老师反馈“我改了哪一格、预期怎样、实际听见怎样”，或直接追问不清楚的概念。勾选与答案不会自动变成学习记录。
