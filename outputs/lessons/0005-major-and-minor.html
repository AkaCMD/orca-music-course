ORCA / MUSIC FOR GAMES / LESSON 05

给旋律选择一套音

用同一个主音 C，对照大调与自然小调的音阶。

约 20 分钟 · 终端 Orca · GeneralUser GS

完成这一课：用限定音集写出两个短动机，并能说出改变了哪几个音。

先回想一个旧问题

不看速查，先说 C-E 与 C-G 各相差几个半音。答不出就回第 4 课试听，不需要重新读整课。

这次需要的知识

音阶为旋律提供有序的音集

C 大调一八度为 C D E F G A B 高C，相邻距离为 2、2、1、2、2、2、1 个半音。我们把这里反复回到的 C 作为主音，先从“有一个听觉上的落脚点”去体会。

自然小调改变三个音级

同以 C 为主音的自然小调是 C D E♭ F G A♭ B♭ 高C，距离为 2、1、2、2、1、2、2。相对于 C 大调，第 3、6、7 级各降低半音。大小调的听感还取决于节奏、音色与上下文，不为游戏情绪提供唯一答案。

代码拼写与乐理拼写要对应

Orca 的音名只用字母，小写 d、g、a 分别发 D♯、G♯、A♯，在当前十二平均律中与 E♭、A♭、B♭ 同音。示例用 CDdFGgaJ 发出 C 自然小调，但说明和分析时仍写 E♭、A♭、B♭。

在终端中练习

先保存已有作品；Ctrl+D 或 F1 打开菜单，在 Open... 加载示例，在 Set BPM... 设 90。空格暂停，Ctrl+R 归零，再开始比较。

  1. 交替听两个上行音阶。先跟着唱或用手势标高低，不要求一次唱准所有音。
  2. 打开大调版，找到 CDEFGABJ。将它改成 CDdFGgaJ，保持 8 步与 BPM 不变。
  3. 从两套音集中各挑 4 个音，写一个以 C 开始、C 结束的版本。允许中间重复。
  4. 把同一节奏的两版放到你选择的游戏画面中，说明哪个更合适；不要只写“大调开心、小调悲伤”。

编辑提示：把 CDEFGABJ 与 CDdFGgaJ 放在 T 后的 8 个音名位置。每个字符占一格，大小写有发声意义。

检查理解

C 大调变成同主音的 C 自然小调，E 应改成什么？

先凭记忆作答，选择后即时反馈。

显示判断方法

第 3 级 E 降低半音为 E♭，在这个 Orca 示例中用 d 发出。先预测再验证，检查自己能否应用概念。

做一份自己的版本

为“旧城白天”和“旧城夜晚”各写一个四音动机。记录主音、音集以及至少一个实际改变的音。若你更喜欢其中一版，也说明原因。

把原版与自己的版本各保存一份。先只改变一个量做比较，再决定是否保留。

自评与复习

隔一段时间再来：先不看网格说出做法，再打开文件核对。向老师反馈“我改了哪一格、预期怎样、实际听见怎样”，或直接追问不清楚的概念。勾选与答案不会自动变成学习记录。
