ORCA / MUSIC FOR GAMES / LESSON 06

让三个音同时说话

从旋律音程走向大、小三和弦。

约 18 分钟 · 终端 Orca · GeneralUser GS

完成这一课：在 Orca 中同时发出 C 大三和弦与 C 小三和弦，并只改中间一个音完成转换。

先回想一个旧问题

回想第 5 课：C 大调与 C 自然小调的第 3 级分别是什么音？这一次让它们与 C、G 同时发声。

这次需要的知识

三和弦把两个三度叠起来

根音 C、三音 E、五音 G 组成 C 大三和弦；相对根音的半音距离为 0、4、7。C 小三和弦为 C、E♭、G，对应 0、3、7。这两个例子只改变三音。

同时发声与依次发声不同

把 C、E、G 一起弹是柱式和弦；把它们先后弹可以形成分解和弦。它们使用相同的三个音，但时间安排不同。在 Orca 中，三个同步触发的 MIDI 运算符可以组成柱式和弦。

用音区与力度控制清晰度

三个音都很低且很响时，声音可能拥挤。本课先在同一中音区、较低力度比较。每小节触发一次，门长 12 帧留出释放空间；这是本次编配选择。

在终端中练习

先保存已有作品；Ctrl+D 或 F1 打开菜单，在 Open... 加载示例，在 Set BPM... 设 90。空格暂停，Ctrl+R 归零，再开始比较。

  1. 看见文件中三个独立块，分别负责 C、E、G，每块都有自己的 MIDI 运算符。设 90 BPM，按 Ctrl+R 归零再播放。
  2. 暂停，只把中间块 T 后的 E 改成小写 d。根音和五音保持不动。
  3. 再把 d 恢复成 E，反复比较几次。用“中间音低半音”解释变化。
  4. 把三块的音区一起升高 1，再一起恢复，判断和弦类型是否改变。

编辑提示：三个块自上而下为根音、三音、五音。只改各块 T 后的单个音名；同步的 Dg 每 16 帧触发一次，g 是十进制 16。

检查理解

C-E-G 变成 C-E♭-G 时，哪个和弦成员改变？

先凭记忆作答，选择后即时反馈。

显示判断方法

根音 C 和五音 G 保持，三音 E 降低半音，得到 C 小三和弦。先预测再验证，检查自己能否应用概念。

做一份自己的版本

保存两版和弦网格，在笔记写出它们的根音、三音、五音和相对根音的半音数。再为一个游戏菜单选择一版，并说明留白、音区或力度的理由。

把原版与自己的版本各保存一份。先只改变一个量做比较，再决定是否保留。

自评与复习

隔一段时间再来：先不看网格说出做法，再打开文件核对。向老师反馈“我改了哪一格、预期怎样、实际听见怎样”，或直接追问不清楚的概念。勾选与答案不会自动变成学习记录。
