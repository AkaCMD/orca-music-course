01从一个音到四个音

上一课改变音符的疏密。这一课保持 90 BPM、每拍一次发声，换成不同的音高。音高是声音的高低，音量是声音的大小。

我们先用同一音区的四个音：C、D、E、G，音高依次升高。本课把 C 当作 do，可以轻声唱成「do、re、mi、sol」。这四个音选自 C 大调；完整音阶以后再学。[1]

这些音按时间先后连成旋律。这里把四拍的小片段作为一个动机：一段可以重复、改变、继续发展的短小音乐想法。[3]先试着跟唱它，唱不准也可以用手势比出高低。

02听见旋律的方向

同一套 Saw Lead 音源 · 每拍一个音 · 四拍循环

切换两个版本，手仍匀速拍「1、2、3、4」。注意四音内部向上或向下的走向；循环接回开头时还会发生一次跳转。

点击后试听。可用上方选单写出自己的四个音，下方网格会同步更新。

...4C4..........
..D404TCDEG.....
...:05C81.......

想象角色走近一扇刚打开的门。你更愿意用哪一个版本？说出听感与画面的联系。上行和下行都可以服务不同情绪，先比较，不给它们固定贴上「开心」或「悲伤」的标签。

03在终端中播放四音循环

  1. 先按 Ctrl + S 保存当前作品。按 Ctrl + D 或 F1，选择 Open...，打开 03-four-note-melody.orca。
  2. 在同一主菜单选择 Set BPM...，设为 90。按 Ctrl + R 将帧数归零，用空格播放或暂停。应听到 C、D、E、G 反复出现，每拍一个音。
  3. 暂停，只改 T 右侧的四个字母，把 CDEG 改成 GEDC。再播放，对照网页试听。

新位置：/home/cmd/git-repos/orca-music-course/outputs/patterns/03-four-note-melody.orca。也可在新终端运行 orca --bpm 90 文件路径。

网格中的 4C4 提供每拍推进一次的 0、1、2、3 计数，T 据此依次选取右侧四个音，把当前音名送到下方 MIDI 音名格。D4 负责每拍触发一次。[2]

第三行的音名会自动更新，请改 T 后面的音符表。本课先使用这套播放结构，不要求凭记忆重建计数器。可打开下行版文件核对；网格位置与大小写都要保留。

音名 C 与运算符 C 的区别

第一行的 C 位于运算位置，是 Clock，负责计数。T 右侧的 C 是音符表中的数据，MIDI 音名格里的 C 表示 C 音。Orca 根据它的位置与端口用途解释字符。[2]

04先预测，再验证

从 CDEG 改为 GEDC，保持所有数字不动。直接改变的是哪一项？

选择后会即时反馈。

现在写一个自己的四音动机，每格从 C、D、E、G 中选一个，允许重复。先用手势预测走向，再试听，最后把同样四个字母写进 Orca。给它起一个与游戏画面有关的名字，并保存为新文件。

再只改最后一个音，听它怎样接回第一个音。无需把它做成一整首曲子；这一课的成果就是一个能控制、能解释的四音循环。

05带回聊天的一句话

「我的四个音是 ____，我想把它放在 ____ 的场景，因为 ____。」也说说：你最后改的是哪一个音，听起来有什么变化？可以把不清楚的地方直接问老师。

下次先凭记忆说出自己的四个音，再打开文件核对。如果记得住，试着轻声哼一遍；下一课再用重复与变化，把短动机发展成更长的乐句。

本课来源

推荐先读 Open Music Theory：Scales and scale degrees 的开头与 major scale 部分，只对照音名和由低到高的排列，不必背全章。

  3. Robert Hutchinson：Motive，University of Puget Sound 乐理教材，用于核对动机的定义与重复、变化。
