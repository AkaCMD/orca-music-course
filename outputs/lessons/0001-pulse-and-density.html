01先听，再改

用手匀速轻拍桌面，口中数「1、2、3、4」。这四拍组成我们练习中的一个小节。BPM 表示每分钟有多少拍；这里固定为 90。[1]

试听对照 · Saw Lead 合成器 · 90 BPM

每四格是一拍，绿色格发声。试着保持手拍速度不变，再切到 D2。

点击后才会发声。网页与终端使用同一套 GeneralUser GS 的 Saw Lead 音色。

.D4.....
........
.:05C81.

在 Orca 的普通内部时钟下，一拍有 4 帧。这个例子中，D4 每 4 帧触发一次，D2 每 2 帧触发一次。因此它们分别在一小节里发声 4 次与 8 次。BPM 保持不变。[2, 3]

把 D4 想象成角色平稳行走，把 D2 放进同一画面。你是否感到更忙、更紧张，或更机械？这是一次配乐判断练习，答案取决于画面与听感。

课程基础音色：Saw Lead（锯齿波合成器）。起音清楚，适合对照节奏；可延长音符或叠加多个音来练旋律与和弦。试听一段旋律与和弦。

02在 Orca 中让它发声

本页使用本地安装的 终端 Orca。先保存你已有的作品。Orca 发送 MIDI 音符指令，实际声音由音源产生。[4]

  1. 按 Ctrl + S 保存当前作品。按 Ctrl + D 或 F1 打开主菜单。
  2. 选择 Open...，打开 01-pulse.orca。本地路径为 /home/cmd/Documents/Codex/2026-10-25/new-chat/outputs/patterns/01-pulse.orca。
  3. 再次打开主菜单，选择 Set BPM...，设为 90。.orca 网格文件本身不保存 BPM。
  4. 观察帧数是否增加；如果暂停，按空格开始。你应该听见同一个音均匀重复。空格也可暂停。

也可以在新终端运行 orca --bpm 90 /home/cmd/Documents/Codex/2026-10-25/new-chat/outputs/patterns/01-pulse.orca。

.D4.....
........
.:05C81.

D 在下方一格生成短暂的 * 触发信号。第三行的 : 收到相邻信号后发送一个音符。[2]

中间那行要留着。D 与 : 必须在同一列，隔一行；* 会自动出现，不用手填。点号是空格位。

保留大写 D 和 C。终端版的 5C 对应 MIDI 60，与本页试听音高一致。这里的 C 是音名；其余参数可看速查表，先不必背。

有闪动，但没有声音

按 Ctrl + D 或 F1，选择 MIDI Output...，选中 FLUID Synth 对应的输出。Midi Through 是 MIDI 转发端口，本身不产生声音。

当前课程音源为 GeneralUser GS，基础音色为 Saw Lead。网页试听由同一 SoundFont、同一预置与效果设置生成，第一课的音高、力度和时值也与终端练习一致。

若仍无声，告诉聊天里的老师 MIDI Output 中的设备名，以及帧数是否变化。

03只改一个数字

先猜一猜：保持 90 BPM 与第三行不动，把 D4 改成 D2，会听见什么？

先作答，再去 Orca 验证。

暂停 Orca，点中 D 右侧的 4，输入 2，然后继续播放。对照手拍：每拍能否听到两个音？需要恢复时，把 2 改回 4；也可打开 02-density.orca 对照。

给两种版本各想一个游戏场景，并用一句话说明理由。例如「我选 ___ 给 ___，因为听起来 ___」。感受可以不同，但请准确说出你改了哪个参数。

04离开屏幕，回想一次

下次练习前，先凭记忆回答：怎样让音符变密，同时保留相同的 BPM？再打开文件验证。这些勾选与页面答题不会自动发送到聊天。

把你的实际听感告诉聊天里的老师；任何不清楚的地方都可以追问。确认这一步后，下一课再让音高变化，做第一个短旋律。
