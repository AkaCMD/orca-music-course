ORCA / REFERENCE 01

拍子与触发

先查词，再回到声音里验证。

本课词汇

词含义本课用法
拍（beat）用来匀速计数的时间单位手拍「1、2、3、4」
速度（tempo / BPM）这里以每分钟的拍数表示90 BPM
小节（bar）按拍的分组划出的单位练习约定四拍一组
音符密度这里指单位时间内发声的次数相同 BPM 下，D2 比 D4 密
帧（frame）Orca 的一次计算步进普通内部时钟下每拍 4 帧
触发（bang）Orca 中用 * 表示的信号激活相邻的 MIDI 运算符

乐理术语依据 Open Music Theory；Orca 术语依据作者手册与时钟实现。

最小可听网格

.D4.....
........
.:05C81.

D4 左边为空时，本例每 4 帧触发一次。第二行接收自动生成的 *，第三行的 : 发送 MIDI。保持三行与列对齐。

: 后的位置本例值作用
10MIDI 通道编号 0，对应通常称呼的第 1 通道
25终端版的音区编号；5C 对应 MIDI 60
3C音名 C；此处保持大写
48力度，影响音源的响度或音色反应
51保持音符的帧数；音源可能仍有释放尾音

参数与端口来源：官方 MIDI 说明与运算符实现。

终端版常用操作

Ctrl + D 或 F1 打开主菜单。在 Open... 打开网格，在 Set BPM... 设置速度，在 MIDI Output... 选择音源。空格播放或暂停，Ctrl + S 保存。

.orca 网格不包含 BPM 设置。本课使用 90 BPM，也可以启动时传入 orca --bpm 90 文件路径。

课程音源为 GeneralUser GS，通道 0 的基础音色为 Saw Lead（程序编号 81，bank 0）。网页试听由同一音源和设置生成。试听音色。

依据终端版作者手册与本地 tui_main.c，菜单及音高映射于 2026-10-25 核对。
